## 研究问题
在无线通信环境中，信道状态动态变化，传统信道选择自适应差，易发生信道冲突、吞吐量下降。本文使用Q‑learning设计信道选择策略，仿真分析吞吐量、冲突概率，验证该方法的有效性。
